مرحله ۱ — خارج کردن از حالت فشرده
----------------------------------------------------------------

فایل  PersianDateTool.rar  را روی درایو C کپی کنید و با
برنامه WinRAR یا 7-Zip از حالت فشرده خارج کنید. پس از
خارج کردن، مسیر نهایی باید دقیقاً به این شکل باشد:

    C:\PersianDateTool\

ساختار فایل‌ها بعد از خارج کردن از حالت فشرده:

    C:\PersianDateTool\
    ├── dist\
    │   ├── PersianDateConverter.exe              (رابط گرافیکی)
    │   ├── RunHidden.vbs                         (مخفی کردن پنجره مشکی)
    │   └── PersianDateConverterCLI\
    │       ├── PersianDateConverterCLI.exe       (برنامه اصلی)
    │       └── _internal\                        (فایل‌های ضروری برنامه)
    └── word\
        └── ConvertPersianDate.bas                (فایل ماکرو برای Word)


  ⚠ مهم: پوشه باید دقیقاً در  C:\PersianDateTool\  قرار بگیرد.
    برنامه در جای دیگری کار نمی‌کند.

مرحله ۲ — اضافه کردن کد ماکرو به Word
----------------------------------------------------------------

  ۱) از پوشه  dist  فایل  PersianDateConverter.exe  را با
     دوبار کلیک اجرا کنید.

  ۲) به تب  Word Macro  بروید.

  ۳) روی دکمه  Copy macro to clipboard  کلیک کنید.

  ۴) یک فایل Word باز کنید.

  ۵) کلیدهای  Alt + F11  را با هم بفشارید تا پنجره VBA باز شود.

  ۶) در منوی بالا:  Insert  →  Module
     یک پنجره سفید خالی باز می‌شود.

  ۷) کلیدهای  Ctrl + V  را بفشارید تا کد ماکرو در آن پنجره
     کپی شود.

  ۸) کلیدهای  Ctrl + S  را بفشارید.

  ۹) Word می‌پرسد: "Save changes to the Normal template?"
     روی  Yes  کلیک کنید.

  ۱۰) کلیدهای  Alt + Q  را بفشارید تا به Word برگردید.


  ─── روش جایگزین (سریع‌تر) ───────────────────────────

  به جای مراحل ۱ تا ۷، می‌توانید فایل آماده ماکرو را
  مستقیماً به Word اضافه کنید:

  ۱) فایل Word باز کنید.
  ۲) Alt + F11 را بفشارید.
  ۳) از منوی  File  →  Import File…
  ۴) به این آدرس بروید:
        C:\PersianDateTool\word\ConvertPersianDate.bas
  ۵) فایل را انتخاب کنید و Open کنید.
  ۶) Ctrl + S بزنید و روی Yes کلیک کنید.
  ۷) Alt + Q برای بازگشت به Word.

  هر دو روش نتیجه یکسان دارند.

مرحله ۳ — تعیین کلید میانبر برای ماکرو
----------------------------------------------------------------

  ۱) در Word یک فایل خالی باز کنید.

  ۲) از منو:  File  →  Options  →  Customize Ribbon

  ۳) در پایین پنجره روی
     "Keyboard shortcuts: Customize…"  کلیک کنید.

  ۴) در ستون  Categories  (سمت چپ) تا پایین بروید و روی
     Macros  کلیک کنید.

  ۵) در ستون  Macros  (سمت راست) روی
     ConvertPersianDate  کلیک کنید.

  ۶) در کادر  Press new shortcut key  کلیک کنید و یک کلید
     میانبر بزنید، برای مثال  F2 .

  ۷) روی دکمه  Assign  کلیک کنید.

  ۸) روی  Close  کلیک کنید تا پنجره بسته شود.

  حالا کلید  F2  به ماکرو اختصاص داده شده است.


  ─── تنظیم میانبرهای اختیاری برای فرمت‌های دیگر ───────

  ماکرو هفت زیر برنامه دارد. هر کدام یک فرمت تاریخ
  مختلف می‌دهد. می‌توانید برای هر کدام یک کلید میانبر
  جدا تعیین کنید:

    ┌─────────────────────────────────────┬──────────┬──────────────────────────────┐
    │ نام ماکرو                            │ کلید     │ خروجی                        │
    ├─────────────────────────────────────┼──────────┼──────────────────────────────┤
    │ ConvertPersianDate                  │ F2       │ فرمت انتخاب‌شده در برنامه    │
    │ ConvertPersianDate_Full             │ F3       │ September 17, 2024           │
    │ ConvertPersianDate_Abbrev           │ F4       │ Sep. 17, 2024                │
    │ ConvertPersianDate_British          │ F6       │ 17 September 2024            │
    │ ConvertPersianDate_BritishAbbrev    │ F7       │ 17 Sep. 2024                 │
    │ ConvertPersianDate_ISO              │ F8       │ 2024-09-17                   │
    │ ConvertPersianDate_DotISO           │ F9       │ 2024.09.17                   │
    │ ConvertPersianDate_SlashUS          │ F10      │ 09/17/2024                   │
    └─────────────────────────────────────┴──────────┴──────────────────────────────┘

  برای تعیین هر کلید، مراحل ۲ تا ۷ بالا را تکرار کنید و
  فقط نام ماکرو و کلید را عوض کنید.


----------------------------------------------------------------
مرحله ۴ — استفاده روزمره
----------------------------------------------------------------

  در هر جای فایل Word:

    ۱) کلید میانبر را بزنید (مثلاً F2).

    ۲) پنجره ورودی تاریخ ظاهر می‌شود.

    ۳) تاریخ شمسی را به فرمت  YYYY/MM/DD  وارد کنید.
       مثال:
            1403/06/27
            1364/01/20
            1403/1/1

    ۴) روی OK کلیک کنید.

  تاریخ تبدیل‌شده دقیقاً در محل کرسر درج می‌شود.


  ─── نکات مهم ────────────────────────────────────────

  ▸ تاریخ‌ها را با صفحه‌کلید انگلیسی وارد کنید.

  ▸ از اسلش ( / ) استفاده کنید، نه خط تیره ( - ).

  ▸ در فایل‌های محافظت‌شده (فرم‌دار) هم کار می‌کند:
    اگر فیلد فرم باشد، مستقیماً پر می‌شود. اگر فایل
    با رمز محافظت شده باشد، یک بار رمز پرسیده می‌شود.


----------------------------------------------------------------
مرحله ۵ — تغییر فرمت پیش‌فرض F2
----------------------------------------------------------------

  کلید F2 از فرمتی استفاده می‌کند که در برنامه اصلی
  انتخاب کرده‌اید.

  برای تغییر فرمت پیش‌فرض:

    ۱) فایل زیر را با دوبار کلیک اجرا کنید:
          C:\PersianDateTool\dist\PersianDateConverter.exe

    ۲) در تب  Single Date  فرمت دلخواه را با کلیک روی
       دکمه رادیویی آن انتخاب کنید.

    ۳) برنامه را ببندید.

  از این پس، F2 با فرمت جدید کار می‌کند.


----------------------------------------------------------------
مرحله ۶ — استفاده گروهی (Batch)
----------------------------------------------------------------

  برای تبدیل تمام تاریخ‌های یک یا چند فایل Word به صورت
  همزمان:

    ۱) فایل زیر را اجرا کنید:
          C:\PersianDateTool\dist\PersianDateConverter.exe

    ۲) به تب  Word Files (Batch)  بروید.

    ۳) در قسمت  Input folder  پوشه‌ای که فایل‌های Word
       در آن قرار دارد را انتخاب کنید.

    ۴) در قسمت  Output folder  پوشه مقصد را انتخاب کنید.

    ۵) از منوی  Format  فرمت دلخواه را انتخاب کنید.

    ۶) روی  Convert Word Files  کلیک کنید.

  برنامه تمام فایل‌های .docx موجود در پوشه ورودی را
  اسکن می‌کند، تاریخ‌های موجود به فرمت شمسی YYYY/MM/DD
  را پیدا و تبدیل می‌کند، و فایل‌های جدید را با پسوند
  _updated.docx  در پوشه مقصد ذخیره می‌کند.

  ⚠ فایل‌های اصلی دست‌نخورده باقی می‌مانند.

  نمونه فایل تست:
    C:\PersianDateTool\dist\batch test.docx


----------------------------------------------------------------
نکات عیب‌یابی
----------------------------------------------------------------

  مشکل: هیچ چیزی درج نمی‌شود و خطایی هم نمایش داده نمی‌شود.
  راه‌حل: مطمئن شوید این دو فایل وجود دارند:
            C:\PersianDateTool\dist\PersianDateConverterCLI\PersianDateConverterCLI.exe
            C:\PersianDateTool\dist\RunHidden.vbs

  مشکل: پیام "Error: Please enter a valid Persian date"
  راه‌حل: تاریخ را دقیقاً به فرمت  YYYY/MM/DD  وارد کنید.
          اعداد انگلیسی، اسلش (/)، بدون فاصله.

  مشکل: یک پنجره مشکی لحظه‌ای باز و بسته می‌شود.
  راه‌حل: ماکرو نسخه قدیمی است. فایل ماکرو جدید را
          دوباره وارد کنید (مرحله ۲، روش جایگزین).

  مشکل: حروف عربی به شکل  ?????  یا مربع نمایش داده می‌شوند.
  راه‌حل: همان بالا. ماکرو نسخه قدیمی است.

  مشکل: کلید میانبر کار نمی‌کند.
  راه‌حل: ماکرو در قالب Normal ذخیره نشده است.
          Alt + F11 → Ctrl + S → Yes.

  مشکل: پیام "The document is protected with a password"
  راه‌حل: برنامه یک بار رمز را می‌پرسد. اگر رمز را
          نمی‌دانید، فایل را دستی از حالت محافظت خارج
          کنید (Review → Restrict Editing → Stop Protection)
          و ذخیره کنید.

  مشکل: ماکرو بعد از بستن Word ناپدید می‌شود.
  راه‌حل: هنگام پرسش Word، حتماً روی Yes کلیک کنید.


----------------------------------------------------------------
جابجایی به پوشه دیگر
----------------------------------------------------------------

  اگر مجبورید پوشه را در جای دیگری نصب کنید (مثلاً روی
  درایو D):

    ۱) پوشه را در محل جدید کپی کنید.

    ۲) در Word:  Alt + F11  →  ماژول ConvertPersianDate

    ۳) این دو خط را پیدا کنید:

          exePath = "C:\PersianDateTool\dist\PersianDateConverterCLI\PersianDateConverterCLI.exe"
          vbsPath = "C:\PersianDateTool\dist\RunHidden.vbs"

    ۴) مسیرها را به محل جدید تغییر دهید. مثال:

          exePath = "D:\Tools\PersianDateTool\dist\PersianDateConverterCLI\PersianDateConverterCLI.exe"
          vbsPath = "D:\Tools\PersianDateTool\dist\RunHidden.vbs"

    ۵) Ctrl + S → Yes.
